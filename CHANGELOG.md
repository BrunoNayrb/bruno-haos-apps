# Changelog

Home Assistant shows the changelog that lives next to each add-on, not this file.

| Add-on | Changelog Home Assistant reads |
|--------|--------------------------------|
| NaviRadio | [naviradio/CHANGELOG.md](naviradio/CHANGELOG.md) |
| Soulbeet | [soulbeet/CHANGELOG.md](soulbeet/CHANGELOG.md) |
| Soulbeet Bulk | [soulbeet-bulk/CHANGELOG.md](soulbeet-bulk/CHANGELOG.md) |

When an add-on version changes, add the new version at the top of that add-on's `CHANGELOG.md` in the same commit as the `config.yaml` version bump. Home Assistant reads it after the add-on repository is reloaded. Do not list commits that were only a failed build.
